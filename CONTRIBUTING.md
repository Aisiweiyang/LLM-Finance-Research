# Contributing

Install with python -m pip install -e ".[dev]" and run python -m pytest -q.

Changes to statistical methods need an independently calculated numerical case,
relevant failure cases, and a methods note. A checksum or copied implementation
formula alone is not a method validation. Keep collection opt-in and imports free
of network or filesystem side effects.

Use new output directories and explicit data/source versions. Never commit keys,
personal paths, raw market histories, downloaded platform responses, or claims
that a synthetic demo reproduced an empirical paper.

Open an issue describing input schema, expected behavior and a minimal redacted
example. Contributions must preserve third-party attribution and data conditions.
