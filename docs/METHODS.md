# 方法与适用范围

## 1. 市场模型事件研究

模型为 r_it = alpha_i + beta_i * r_mt + epsilon_it，使用对数收益。默认事件窗 [-10,+10]，估计窗 [-130,-11]，以基准市场日历的交易会话计数。配置明确保留两窗不重叠。

事件 CAR 为窗口内异常收益之和。报告的预测误差方差包含估计 alpha/beta 的不确定性：

```text
Var(CAR) = sigma² * (L + s' * inverse(X'X) * s)
s = sum of the event-window design rows [1, market_return]
```

该公式依赖市场模型残差条件，不自动修复事件期间异方差、序列相关或跨公司共同冲击。本版本不提供将多事件视为独立样本的汇总显著性，也不推断因果效应。公司重复事件、共同公告日和行业冲击需要独立研究设计。

同一证券事件窗重叠时，默认保留按日期和 event_id 排序的第一个合格观测，其他观测写入拒绝表；可显式配置保留重叠，但不会因此获得独立性。股票缺失交易会话、基准缺失、估计样本不足和零残差分别处理。

事件日期必须由研究者根据首次公开时间、时区、开收盘时点构造。程序的“当日或后续基准会话”规则不能替代这项核验。用户提供的 adjusted_close 是否真正复权，也需由其来源证据支持。

## 2. 能力—价格前沿

模型 A 同时不贵于模型 B、能力不低于 B，且至少一个维度严格更优时，A 支配 B。这包含“相同能力但更便宜”的情况。相同坐标的两个模型可同时位于前沿。无效能力、非有限值及非正价格记录在排除表中。

这是截面分析。不能用当前截面价格配历史模型创建日期推断真实历史价格下降或能力增长；模型下架、不同评测版本与路由别名也会造成偏差。

## 3. OLS 与财务面板

默认始终加入截距，分类固定效应省略一个基准组。模型秩不足时明确拒绝。y、X、聚类组在同一完整观测掩码下对齐，不按不同索引分别筛选。输出缺失排除位置、样本量与推断方式。

HC1 或公司聚类标准误由 statsmodels 计算，使用 t 分布推断。少于 30 个聚类时明确警示；这个经验提示不是“小样本推断已解决”的认证。当前版本不提供未验证的自制 wild bootstrap 或分层贝叶斯算法。

面板滞后变量需按真实财季构造；缺季时简单 shift 不能视为一个季度。季度/财年对齐、事后修订和可得时间仍属于数据构造任务。

## 4. XBRL 现金流去累计化

以 10-K 年报事实锚定完整财年。10-Q 中滚动十二个月事实不能建立财年边界。由年内累计值差分，或由已知离散季度补齐；只输出完整前缀。只有年报而没有季度前缀时不伪造第四季度。

优先采用同期间最后申报的事实；同期间同申报日数值冲突则拒绝。可用 --as-of 限制 filed 日期，避免直接使用后续重述。输出使用的申报日期和 accession；没有 accession 的源记录不能因此获得追溯认证。

当前范围是指定 taxonomy、unit、cash-flow tag 的有限实用方法，未涵盖所有 IFRS、过渡财年、公司特殊标签与分部事实。供应商公告、原表语义和季度总额仍需人工抽核。filed 日期粒度不等于盘中首次公开时间。

## 5. 运行回执

manifest 记录输入哈希、参数、输出库存及哈希。verify 默认只校验输出；提供 --input-root 才重验原输入。回执不是数字签名，不能认证发行者；一致的文件哈希不证明来源真实、经济识别有效或收益可交易。

失败运行保留 failure.json 并返回非零状态；不会生成成功 manifest。命令行输出目录为创建式，防止覆盖旧结果。
