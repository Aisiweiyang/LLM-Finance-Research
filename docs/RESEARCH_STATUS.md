# 研究状态与历史问题

## 本次开源范围（2026-10-29）

开源版整理为独立 Python 工具包，保持 LLM 产业实证主题，提炼原探索项目的方法并删除重复和不可发布内容。它不是原论文表格的复现发布。

本地验证分别记录数值检查、命令行验证与合成演示。CI 状态以 GitHub Actions 实际运行结果为准。新工具未重新采集或运行完整真实数据研究，不报告“开源折扣”“披露时滞被定价”或事件因果效应为已确认发现。

## 旧结果的证据边界

2026-10-22 对原项目的本地核查发现：

- 66 条网安收益样本中，本地 SEC 结构化记录仅 47 条含 Item 1.05，13 条不含，6 条未匹配。这不是严格的 66 条 Item 1.05 样本。
- 31 条披露时滞样本原回归未加截距；同样 HC1/t 推断，加入截距后 p 值约从 0.016 变为 0.775。原显著性对设定敏感。
- 清单未覆盖后加入的手册脚本；原套件为 9 通过、1 失败。
- 自主评测 run_evals.py 只有骨架，提供密钥仍不能运行完整评测。

这些数值是旧版核查记录，未在本次重新运行全数据研究。旧报告和结果表不进入公开初始提交，防止它们被当作本工具的当前输出或已复现结论。
