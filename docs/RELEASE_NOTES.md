# 开源整理记录

## 0.1.0 / 2026-10-29

从原目录 LLM金融实证研究 提炼出独立项目 llm-finance-research，采用可安装的 src 布局。开源仓库使用干净初始历史；原研究目录和原Git历史保留在本地，不复制到公开仓库。

### 保留和提炼

- 定价前沿、市场模型事件研究、财务现金流去累计化、带固定效应的OLS与聚类推断。
- SEC 精确项目号筛选、固定 LiteLLM 提交的价格快照、来源回执。
- 历史模型发布线索与公开链接，明确标记尚未重新核实。
- 可配置输入、排除记录、失败回执、SHA-256 manifest 与独立数值测试。

### 从开源版移除

| 旧内容 | 原因 |
|---|---|
| backup_phase3_20260910 | 重复旧目录快照；原目录与版本历史留在本地 |
| research_data/data/raw 与大价格历史文件 | 可重新取得的缓存、体积、第三方数据发布条件与证据状态不一致 |
| 旧行情、8-K正文与平台响应 | 不作为开源代码的附带再分发数据 |
| 旧回归结果、图表与论文完成度报告 | 未修正样本与设定问题，不适合作为当前确认结果 |
| phase/round 优化脚本、旧提示词、机器专用手册和docx生成器 | 一次性流程、重复逻辑、过期路径和运行说明 |

| 自制分层模型、价格DiD标签和重复统计实现 | 尚未验证的推断或方法名与计算不一致；保留在本地旧历史，不以稳定API发布 |
| 旧requirements_freeze与结果锚点测试 | 本机依赖与旧数据绑定；替换为安装依赖和独立方法/负面案例测试 |

### 本地恢复

在原研究目录需要查看旧文件时，可使用只读 Git 命令：

```powershell
git show 79960efa567a3636df7949912867702f6ebda86c:README.md
git ls-tree -r --name-only 79960efa567a3636df7949912867702f6ebda86c
```

原工作副本中的大型忽略缓存和重复备份不承诺全部存在于Git。本次开源通过单独提炼目录去除这些内容，不自动删除原始研究资料；需要重建缓存时使用来源接口与合法的数据取得方式。请勿将旧项目历史通过 --all/--mirror 推送到公开仓库。
